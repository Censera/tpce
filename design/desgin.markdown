Commands

```
/tpce <reload|request|accept|decline|back>
/tpr <player>		# Teleport Request
/tpa			# Teleport Accept
/tpd			# Teleport Decline
/tpb			# Teleport Back
/bed			# Teleport To Bed
/home set <name> <primary>	# Set Home (Limit is 3 Home locations)
/home <name>		# Teleport To Home
/home			# Teleport To Home (primary)
/spawn			# Teleport To spawn point
```
